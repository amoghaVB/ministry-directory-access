# Ministry Contact Directory — Access Page

Public GitHub Pages entry point for the private Ministry Contact Directory.

This repository contains only the static access page. It does not contain directory records, workbook data, credentials, authentication code or a copy of the private application. The destination handles sign-in and approved membership. This page does not grant access.

## Hosting

GitHub Pages serves the root of the `main` branch. No build step, package dependencies, JavaScript, analytics or external assets are required.

The button links to the separately hosted secure application. This repository must remain separate from the private application's source and data. Do not add directory records, workbook files, secrets or private application archives here.

## Preview

Serve this directory with a local static HTTP server, then open `index.html`. Changes to `index.html` or `styles.css` are published after pushing to `main` and a successful GitHub Pages build.
